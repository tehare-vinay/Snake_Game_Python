# 🐍 Snake Game — Python & Pygame

A classic Snake Game built using Python and Pygame with modern features like high score tracking and pause functionality.

## 🎮 Features
- Smooth snake movement with arrow keys
- Real-time score tracking
- High Score saved automatically
- Pause and Resume functionality
- Clean Game Over screen
- New High Score detection

## 🛠️ Tech Used
- Python 3
- Pygame library

## ▶️ How to Run

Step 1 - Install pygame
pip install pygame

Step 2 - Run the game
python snake-game.py

## 🎯 Controls

| Key | Action |
|-----|--------|
| ↑ Arrow | Move Up |
| ↓ Arrow | Move Down |
| ← Arrow | Move Left |
| → Arrow | Move Right |
| P | Pause / Resume |
| R | Restart |
| Q | Quit |

## 📁 Project Structure
- snake-game.py — Main game file
- highscore.json — Auto-created to save high score

## 🎯 Learning Outcomes
- Python OOP — Classes and Objects
- Pygame basics — Game loop, Events
- File handling — JSON read/write
